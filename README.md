# GyverTwink
Гирлянда на адресных светодиодах и ESP8266, управление по WiFi.

Главная особенность — **автокалибровка по камере**: телефон по очереди зажигает каждый светодиод и снимает его положение
на кадре. Прошивка запоминает координаты x/y каждого светодиода, и эффекты (градиенты, шум Перлина) строятся по реальной геометрии
гирлянды, а не по номеру светодиода в ленте. Гирлянду можно развесить как угодно: на ёлке, на стене, на окне.

Автор оригинала — AlexGyver ([страница проекта](https://alexgyver.ru/gyvertwink/)), лицензия MIT.
Здесь — развитие проекта; планы и принятые решения лежат в [`docs/`](docs/).

## Что нужно
- Плата на ESP8266 (WeMos D1 mini или NodeMCU).
- Адресная лента или гирлянда WS2812 (5 В) / WS2811 (12 В), блок питания под её ток.
- Кнопка (по желанию, но нужна для входа в настройки WiFi).
- Android-телефон с камерой.

## Схема подключения
Вход ленты (Din) — на **D1**, кнопка — между **D3** и **GND**. Пины и тип ленты меняются в начале `GyverTwink_v1.2.ino`.

| Схема | Файл |
|---|---|
| Минимальная | [`schemes/scheme1.jpg`](schemes/scheme1.jpg) |
| Рекомендуемая (резистор 220 Ом в линии данных, конденсатор 100 мкФ по питанию, диод) | [`schemes/scheme2.jpg`](schemes/scheme2.jpg) |
| С лентами 12 В (WS2811); плату питать отдельно от USB! | [`schemes/scheme3.jpg`](schemes/scheme3.jpg) |

**Про питание.** Один светодиод на полной белой яркости берёт до 60 мА: 100 светодиодов — до 6 А, 500 — до 30 А.
Блок питания должен это выдержать, либо нужно включить ограничение тока (см. ниже).

## Прошивка
Основной способ — PlatformIO (так же прошивка собирается в CI):
```
pip install platformio
pio run -e d1_mini -t upload      # WeMos D1 mini; для NodeMCU: -e nodemcuv2
```
Окружение `d1_mini_legacy` собирает прошивку на старом ядре ESP8266 2.7.x (проверка совместимости).

Настройки в начале [`GyverTwink_v1.2.ino`](firmware/GyverTwink_v1.2/GyverTwink_v1.2.ino):

| Параметр | Что это |
|---|---|
| `LED_PIN`, `BTN_PIN`, `BTN_TOUCH` | пин ленты, пин кнопки, сенсорная ли кнопка |
| `LED_TYPE`, `LED_ORDER` | чип ленты и порядок цветов (если цвета перепутаны — поменяй `GRB` на `RGB`/`BRG`) |
| `LED_MAX` | максимум светодиодов (500) |
| `POWER_LIMIT_MA` | лимит тока по умолчанию, мА; 0 — выключен |
| `GT_AP_SSID`, `GT_AP_PASS` | имя и запасной пароль точки доступа |

PlatformIO сам скачает FastLED 3.5.0, остальные библиотеки лежат в [`libraries/`](libraries/).
В Arduino IDE скетч тоже можно открыть (папка `firmware/GyverTwink_v1.2`): установи FastLED **3.5.0** через менеджер библиотек,
а содержимое [`libraries/`](libraries/) скопируй в папку библиотек Arduino. Этот способ в репозитории не проверяется автоматически.

## Первый запуск
1. Включи гирлянду. На первых трёх светодиодах на секунду загорятся красный, зелёный и синий.
2. При первом запуске откроется **портал настройки**: лента мигает синим, плата создаёт открытую WiFi-сеть `ESP Config`.
   Позже портал открывается, если нажать кнопку в течение 2 секунд после включения.
3. Подключись к `ESP Config` телефоном — откроется страница настройки (если нет, зайди на `192.168.1.1`). Выбери режим:
   - **WiFi settings** — введи имя и пароль домашней сети, гирлянда подключится к роутеру;
   - **Access Point** — гирлянда сама создаёт сеть `GyverTwink`. **Придумай свой пароль (8–31 символ)**: поле обязательное;
   - **Local Mode** — использовать не рекомендуется: если сеть ещё не сохранена, гирлянда создаст точку с запасным паролем из прошивки,
     иначе подключится к ранее сохранённой сети;
   - **Exit Portal** — выйти без изменений (на первом запуске это точка `GyverTwink` с запасным паролем `12345678`).
4. Индикация состояния:

| Лента | Что значит |
|---|---|
| мигает синим | открыт портал настройки |
| мигает жёлтым | подключаемся к роутеру |
| мигнула зелёным | подключилась к роутеру |
| мигнула красным | не удалось подключиться (гирлянда создаст свою точку) |
| мигнула розовым | создана точка доступа |

## Приложение
Android: [Google Play](https://play.google.com/store/apps/details?id=ru.alexgyver.GyverTwink),
[.apk в Releases](https://github.com/UkWood/GyverTwink/releases/tag/app-v1.7) (версия 1.7, без ACK и поля лимита тока).
Исходники — [`processing/GyverTwink`](processing/GyverTwink) (Processing; текущая версия 1.9, **APK из исходников пока не пересобран**).

1. Телефон должен быть в той же сети, что и гирлянда: в домашней WiFi или в точке `GyverTwink`.
2. На вкладке настроек (гаечный ключ) значок обновления ищет гирлянды в сети; маска подсети по умолчанию `255.255.255.0`.
   Найденное устройство выбирается в списке *Connection*.
3. Настройки: количество светодиодов, питание, яркость, таймер выключения, автоматическая или случайная смена эффектов,
   период смены, **ограничение тока** (поле появляется, если прошивка его поддерживает).
4. Вкладка эффектов: 22 эффекта (11 палитр, каждая как градиент и как шум Перлина); для каждого — «избранное»
   (участвует в автосмене), масштаб и скорость.

### Калибровка
Нужна один раз после того, как гирлянда развешена, и повторять при каждом перемещении.
1. Укажи на вкладке настроек точное количество светодиодов.
2. Закрепи телефон неподвижно так, чтобы вся гирлянда была в кадре. Алгоритм ищет самую яркую точку на разностном кадре,
   поэтому лучше затемнить комнату и убрать другие источники света.
3. Вкладка камеры → **Start**. Через пару секунд гирлянда начнёт зажигать светодиоды по очереди (примерно по 2–3 в секунду),
   приложение запишет их положение, процент выполнения показан на экране. **Stop** прерывает калибровку.
4. После окончания координаты сохраняются в памяти гирлянды и переживают перезагрузку.

Если часть светодиодов оказалась не там, это пока нужно исправлять повторной калибровкой (ручная правка координат есть в
[плане развития](docs/ROADMAP.md)).

## Кнопка
- Один клик — включить/выключить.
- Два клика — следующий эффект.
- Удержание — плавное изменение яркости; направление (ярче/темнее) меняется после каждого отпускания.

## Ограничение тока
Если блок питания слабее ленты, задай лимит в приложении (поле *Current limit [mA]*) или в `POWER_LIMIT_MA`. Прошивка снизит яркость так,
чтобы оценочный ток не превысил лимит; 0 — без ограничения. Оценка модельная (FastLED, с поправкой на реальные WS2812),
поэтому в первый раз стоит проверить реальный ток и взять лимит с запасом (например, 80% от тока блока питания).

## Если что-то не работает
| Проблема | Что проверить |
|---|---|
| Гирлянда не находится | телефон и гирлянда в одной сети? маска подсети (по умолчанию `255.255.255.0`); у точки `GyverTwink` нужно подключиться именно к ней |
| Нужно сменить сеть или пароль точки | включи гирлянду и нажми кнопку в течение 2 секунд — откроется портал |
| Цвета перепутаны | `LED_ORDER` в прошивке |
| После калибровки эффекты «не по форме» | повторить калибровку: неподвижный телефон, затемнённая комната, верное число светодиодов |
| Гирлянда перезагружается или мерцает | не хватает питания: уменьши яркость или включи ограничение тока, проверь питание и землю |
