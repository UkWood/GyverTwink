# Чек-лист проверки на настоящей плате

Всё, что описано в `docs/WEB_API.md`, проверено автоматически: логика прошивки собирается и тестируется на ПК (`make -C tests`),
страница — в настоящем Chromium против настоящего кода прошивки, прошивка компилируется в CI для ядер ESP8266 3.x и 2.7.x.
**Не проверено на железе** то, что зависит от платы: сеть и mDNS, флеш-память (LittleFS, OTA), кнопка, настоящая лента, камера телефона.
Этот чек-лист — как закрыть эти пробелы. Если что-то не сработало, запиши номер шага и что увидел — этого достаточно, чтобы найти причину.

Подготовка: прошей плату `pio run -e d1_mini -t upload` (в первый раз — по USB), подключи ленту и кнопку по схеме из README.
По желанию включи отладку в Serial: раскомментируй `DEBUG_SERIAL_GT` в начале `GyverTwink_v1.2.ino` и смотри монитор порта (115200).

## 1. Сеть и страница
| № | Действие | Ожидаемый результат |
|---|---|---|
| 1.1 | Подключи гирлянду к домашней WiFi (портал настройки, см. README) | зелёная вспышка |
| 1.2 | С телефона в той же сети открой `http://gyvertwink.local` | страница открывается, вверху «на связи», в подвале версия `1.3` |
| 1.3 | Если `.local` не открывается — открой по IP | страница открывается (тогда mDNS не работает на этом устройстве — это нормально для части телефонов) |
| 1.4 | Подвал страницы: «свободно NN КБ» | не меньше ~15 КБ; запомни число |
| 1.5 | Оставь страницу открытой на 10 минут | «на связи» не пропадает, свободная память не падает ниже ~10 КБ |

## 2. Управление
| № | Действие | Ожидаемый результат |
|---|---|---|
| 2.1 | Кнопка питания, ползунок яркости | лента реагирует сразу, без заметных рывков |
| 2.2 | Измени яркость кнопкой на гирлянде (удержание) | страница в течение 2 секунд показывает новое значение |
| 2.3 | Лимит тока, число светодиодов, таймер выключения | значения применяются; после выключения и включения питания гирлянды сохраняются |
| 2.4 | Одновременно открой страницу и приложение (если есть), меняй настройки там и там | обе стороны видят изменения друг друга |

## 3. Сцены
| № | Действие | Ожидаемый результат |
|---|---|---|
| 3.1 | Настрой вид, сохрани сцену «Вечер» | в списке появилась |
| 3.2 | Измени настройки, нажми «Применить» | вернулся прежний вид |
| 3.3 | Выключи питание гирлянды на 10 секунд и включи | сцена на месте (проверка LittleFS на плате) |

## 4. Редактор координат
| № | Действие | Ожидаемый результат |
|---|---|---|
| 4.1 | Вкладка «Координаты», листай ◀/▶ | горит именно выбранный светодиод (счёт на странице с единицы) |
| 4.2 | Перетащи точку, «Сохранить», перезагрузи страницу | новое положение сохранилось; эффекты строятся по новой карте |
| 4.3 | Закрой страницу при горящем светодиоде | через минуту гирлянда вернулась к эффектам |

## 5. Калибровка по видео (нужен телефон с камерой)
| № | Действие | Ожидаемый результат |
|---|---|---|
| 5.1 | Гирлянда развешена, телефон закреплён, комната тёмная, вся гирлянда в кадре. «Запустить серию», включи запись | за заданную паузу успеваешь начать запись |
| 5.2 | Дождись конца серии, останови запись | по ходу: вспышка-маркер (несколько светодиодов горят одновременно), затем светодиоды по одному |
| 5.3 | Выбери видео, «Разобрать видео» | не позже пары минут откроется «Координаты»: найдено большинство светодиодов, остальные с пунктирным кольцом |
| 5.4 | Сравни карту с настоящей формой гирлянды, «Сохранить» | форма похожа; эффекты теперь следуют форме |
| 5.5 | Для сравнения повтори калибровку приложением | карты похожи |

Если разбор не нашёл маркер или многие светодиоды: проверь, что запись началась до первой вспышки, камера неподвижна, комната тёмная; попробуй шаг 200 мс.
Если телефон снимает в формате, который браузер не открывает (бывает HEVC), перекодируй в H.264/VP8 или сними другим приложением — страница сообщит «формат не поддерживается».

## 6. Обновление по WiFi
| № | Действие | Ожидаемый результат |
|---|---|---|
| 6.1 | Вкладка «Прошивка»: статус | «Окно закрыто…» |
| 6.2 | Нажми кнопку на гирлянде 3 раза быстро | голубая вспышка; на странице «Окно обновления открыто» с обратным отсчётом |
| 6.3 | Выбери `firmware.bin` из артефакта CI, «Загрузить» | прогресс, «Прошивка записана», перезагрузка, затем «Готово. Версия прошивки: …» |
| 6.4 | Попробуй загрузить ещё раз без трёх нажатий | кнопка недоступна; запрос по сети отклоняется |
| 6.5 | Загрузи не-прошивку (например `.elf`) | предупреждение до загрузки |

Если питание пропало во время записи, плата может не запуститься — тогда прошей по USB. Это общее свойство OTA, а не этой реализации.

## 6а. Новые эффекты (22–27)
| № | Действие | Ожидаемый результат |
|---|---|---|
| 6а.1 | Вкладка «Эффекты»: по очереди выбери «Звёзды», «Бегущие огни», «Огонь», «Дыхание», «Волны по высоте», «Волны от центра» | каждый показывается сразу и выглядит как называется; плавного перехода от прежнего эффекта хватает без рывка |
| 6а.2 | «Огонь»: сравни, где пламя гуще (низ или верх гирлянды) | гуще внизу, языки поднимаются вверх (если наоборот, значит камера при калибровке была перевёрнута: напиши, поменяю направление) |
| 6а.3 | Двигай «Масштаб» и «Скорость» у каждого | значения меняют вид так, как написано в подсказке под ползунками |
| 6а.4 | Отметь новый эффект «избранным», включи автосмену | он появляется в круге смены; без отметки в смену не попадает |
| 6а.5 | Сохрани сцену с новым эффектом, перезагрузи гирлянду, примени сцену | эффект и его настройки вернулись (сцены от прошивки 1.3 тоже должны остаться на месте) |
| 6а.6 | Длинная лента (300+ светодиодов), эффект «Огонь» | анимация не рвётся; страница отзывчива |

## 7. Нагрузка
| № | Действие | Ожидаемый результат |
|---|---|---|
| 7.1 | На длинной ленте (300+ светодиодов) открой страницу и двигай ползунки | страница отзывчива; анимация гирлянды не замирает дольше долей секунды |
| 7.2 | Открой страницу на двух устройствах | работают оба (сервер обслуживает запросы по очереди) |

Что сообщить, если что-то не так: версия прошивки (подвал), число светодиодов, плата, ядро (`pio run` печатает при сборке), номер шага, вывод Serial.
