Формат пакета: {'G','T',x,x...}, где x - байты [0-255]
Приложение - мастер. Отправляет:

{0} - запрос IP
esp отвечает {0, ip}, ip - последний октет адреса

{1} - запрос настроек
esp отвечает {1, колво_led/100, колво_led%100, питание, яркость, автосмена, случайная_смена, период, таймер активен, время таймера}

{2, 0, am1, am2} - отправить кол-во ледов (am1 = колво_led/100, am2 = колво_led%100)
{2, 1, val} - отправить состояние питания
{2, 2, val} - отправить яркость
{2, 3, val} - отправить флаг авто смены режимов
{2, 4, val} - отправить флаг случайной смены режимов
{2, 5, val} - отправить период смены режимов
{2, 6} - следующий эффект
{2, 7} - отправить состояние таймера выключения
{2, 8, val} - отправить время до выключения

{3, 0} - запуск калибровки
{3, 1, n/100, n%100, x, y} - включить светодиод под номером n (от 0 до колво led) и передать координаты по сетке ПРЕДЫДУЩЕГО светодиода
{3, 2} - остановить калибровку

{4, 0, n} - выбрать эффект под номером n
esp отвечает {4, favorite, масштаб, скорость}

{4, 1, val} - установить флаг избранного val
{4, 2, val} - установить масштаб val
{4, 3, val} - установить скорость val

=== Расширение: подтверждение команд (ACK), версия 1 ===
Необязательное. Старые клиенты его не используют и работают как раньше.

{5} - запрос возможностей
esp отвечает {5, ver}, ver - версия расширения (сейчас 1). Нет ответа - прошивка старая, ACK не поддерживает.

Чтобы запросить подтверждение, в старший бит байта команды ставится флаг 0x80, а следом за ним добавляется байт seq (0-255).
Остальные аргументы сдвигаются на 1 байт. Пример: {2, 2, val} с ACK -> {0x82, seq, 2, val}.
esp выполняет команду и отвечает {6, команда, seq, статус}:
  статус 0 - выполнено, 1 - недопустимый аргумент, 2 - неизвестная команда.
Клиент увеличивает seq для каждой новой команды. Если ACK не пришёл - повторяет команду С ТЕМ ЖЕ seq:
esp не выполнит её второй раз (важно для {2, 6}), а только повторит ACK. Запросы {0}, {1}, {4, 0, n}
выполняются заново при каждом повторе, чтобы клиент снова получил ответ с данными.
Для пакетов с флагом "антидребезг" 50 мс отключён: повторы отсеиваются по seq.


=== Расширение: ограничение тока ===
Яркость автоматически снижается так, чтобы потребление ленты не превышало лимит. 0 - лимит выключен.
Лимит задаётся в мА (значение пересчитывается с коэффициентом 0.7 под реальный ток WS2812, см. power.ino) и хранится в EEPROM.

{2, 9, mA/100, mA%100} - установить лимит
{7} - запрос лимита, esp отвечает {7, mA/100, mA%100}
Лимит по умолчанию - POWER_LIMIT_MA в прошивке (0). Команды работают и с флагом ACK.
