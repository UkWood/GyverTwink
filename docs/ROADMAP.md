2. Протокол только расширяется: старые команды и Android-приложение продолжают работать (ACK, токен — опциональны).
3. Каждый этап — отдельный PR с зелёным CI.

## Этап 2. Веб-интерфейс на ESP — ✅ выполнен
Всё проверено автоматически (юнит-тесты логики на ПК, e2e в настоящем Chromium против настоящего кода прошивки, сборка для трёх окружений), **кроме того, что зависит от платы**
(сеть и mDNS, LittleFS и OTA во флеше, кнопка, настоящая лента и камера телефона): для этого есть пошаговый `docs/HARDWARE_CHECKLIST.md`.
- ✅ Каркас: встроенный `ESP8266WebServer` + JSON API (вместо ESPAsyncWebServer + WebSocket, см. DECISIONS), страница gzip вшита в прошивку; управление питанием, яркостью, эффектами, таймером, лимитом тока — `docs/WEB_API.md`
- ✅ mDNS (`gyvertwink.local`); адрес по IP показывает приложение. QR-код не делаем: страница не может показать QR на саму себя, а адрес уже есть в приложении и README
- ✅ Сцены/пресеты в LittleFS: 8 мест, 89 байт на сцену, контрольная сумма, запись через временный файл (`scenes.ino`, вкладка «Сцены», `docs/WEB_API.md`)
- ✅ Редактор координат: холст с перетаскиванием и правкой числами, подсветка выбранного светодиода на гирлянде, поиск подозрительных точек, сохранение в EEPROM (`coords.ino`, вкладка «Координаты»)
- ✅ Калибровка по видео: серия на гирлянде (`vcalib.ino`: пауза, маркер, светодиоды по одному) + разбор видео в браузере (`web/calib.js`), результат — в редактор координат (`docs/WEB_API.md`)
- ✅ OTA-обновление прошивки по WiFi: окно открывается тремя нажатиями кнопки (`ota.ino`, вкладка «Прошивка», `docs/WEB_API.md`), CI следит за размером образа
- ✅ Схема «спираль» для цилиндров и конусов (вкладка «Координаты», только веб: `spiralLayout` в `web/app.js`; результат попадает в редактор карты как несохранённая правка); проверено на настоящей ленте владельцем (схема строится, «Перевернуть карту по вертикали» меняет, какой край считается низом)

## Этап 3. Новые возможности — ✅ выполнен (прошивка 1.4; MQTT/Home Assistant отменены владельцем)
- ✅ Новые эффекты (22–27): звёзды, бегущие огни, огонь, «дыхание», волны по высоте и от центра. Настройки в новом блоке EEPROM, сцены v2 (миграция v1), веб; в приложение не добавлены (этап 4); внешний вид проверен на настоящей ленте владельцем (огонь идёт вверх на карте с правильной ориентацией)

- ❌ MQTT / Home Assistant (автообнаружение) — отменено владельцем 2026-10-22, в этап не входит
- ✅ Токен для управления вебом: заголовок `X-GT-Token` на всех API, смена только при открытом окне (3 нажатия кнопки), ограничение подбора, вход на странице. **UDP токена не знает**: по умолчанию открыт, владелец может закрыть команды записи (тогда приложение не управляет); токен в протоколе UDP - вместе с приложением (этап 4)
