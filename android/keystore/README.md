# Ключ подписи приложения

`gyvertwink.jks` - **публичный** ключ подписи проекта (пароль `gyvertwink`, псевдоним `gyvertwink`). Он лежит в репозитории намеренно:
так APK из CI и из релизов подписаны одним и тем же ключом, и новая версия ставится поверх старой без удаления приложения.

Что это значит: подпись не доказывает, что файл собрал владелец (ключ может использовать любой). Ставь APK только из [Releases](https://github.com/UkWood/GyverTwink/releases) этого репозитория.

Свой ключ: задай переменные окружения `GT_KEYSTORE_PATH`, `GT_KEYSTORE_PASSWORD`, `GT_KEY_ALIAS`, `GT_KEY_PASSWORD` (сборка берёт их вместо этого файла). Смена ключа потребует один раз удалить приложение с телефона (Android не ставит обновление с другой подписью).
